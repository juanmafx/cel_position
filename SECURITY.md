# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| Earlier unversioned code | No |

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting on this repository if it is enabled. If it is not, open an issue that asks for a private contact channel, and do not include exploit details in the public issue.

Include the affected version, the browser or Node.js version, reproduction steps, and the expected impact. This is a personal project, so no response time is guaranteed.

## Scope

In scope: the code in `src/`, `tools/`, and the CI workflow.

Out of scope: the security of the host where a copy is deployed.

The audit for this release is in [docs/SECURITY_AUDIT.md](docs/SECURITY_AUDIT.md).
